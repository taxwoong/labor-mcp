# 최저임금 연도별 테이블 (2018~2026)

> MCP 리소스 URI: `labor://table/최저임금-연도별`
> 기준일: 2026-08-28. 수치의 원본은 `labor_constants.MINIMUM_WAGE`·`MW_EXCLUSION_RATIO_*` —
> **이 문서와 코드가 어긋나면 코드 수정이 아니라 둘 다 고시로 재검증할 것.**
> 근거: 최저임금법 제8조·제10조 (고용노동부장관이 매년 8월 5일까지 결정·고시, 다음 연도
> 1월 1일부터 효력). 2026년 적용분은 **2025-08-05 고시** 확인 (개발계획.md 리서치).

## 1. 연도별 시급·월 환산액

월 환산액 = 시급 × 209시간 (주 40시간 + 주휴 8시간, 월 4.345주 — `monthly_standard_hours()`).
주 소정근로시간이 40시간 미만이면 월 기준시간을 비례 산출해 비교해야 한다.

| 적용 연도 | 시급 (원) | 월 환산액 (원, 209h) | 비고 |
|---|---|---|---|
| 2018 | 7,530 | 1,573,770 | 산입범위 구법 체계 (상여·복리후생비 불산입) |
| 2019 | 8,350 | 1,745,150 | 개정 산입범위 첫 적용 연도 |
| 2020 | 8,590 | 1,795,310 | |
| 2021 | 8,720 | 1,822,480 | |
| 2022 | 9,160 | 1,914,440 | |
| 2023 | 9,620 | 2,010,580 | 미산입 비율 마지막 연도 |
| 2024 | 9,860 | 2,060,740 | **산입범위 완전 산입 개시** (매월 지급분 전액) |
| 2025 | 10,030 | 2,096,270 | |
| 2026 | 10,320 | 2,156,880 | 고시 2025-08-05 |

연도별 개별 고시 번호는 이 리서치에서 확정하지 않음 — 필요 시 law.go.kr에서 확인 (확인 필요).

## 2. 산입범위 축소 스케줄 (2018 개정 최저임금법 부칙 — 법률 제15666호)

'매월 1회 이상 정기 지급'되는 정기상여금·현금성 복리후생비 중, **월 환산 최저임금액 대비
아래 비율 이하 부분은 미산입** (비율 초과분만 산입). 2024년부터 비율 0% → 전액 산입.

| 적용 연도 | 정기상여금 미산입 비율 | 현금성 복리후생비 미산입 비율 |
|---|---|---|
| 2019 | 25% | 7% |
| 2020 | 20% | 5% |
| 2021 | 15% | 3% |
| 2022 | 10% | 2% |
| 2023 | 5% | 1% |
| 2024 이후 | 0% (전액 산입) | 0% (전액 산입) |

주의 (검증 로직의 함정 2가지):
1. 위 스케줄은 **매월 지급분에만** 적용 — **격월·분기·반기·연간 지급 상여는 연도 불문
   애초에 불산입** (`labor://table/임금항목-산입매트릭스` 참조).
2. 연장·야간·휴일수당 등 소정근로 외 임금과 현물 지급분은 불산입 (최저임금법 제6조④).
3. 2018년 이전 산입범위는 구법 체계라 이 스케줄로 계산 불가 —
   `labor_constants.mw_exclusion_ratios()`가 명시적 오류를 낸다.

## 3. 수습 감액 3요건 (최저임금법 제5조② + 시행령 제3조)

**세 요건을 모두 충족할 때만** 10% 감액(90% 지급) 가능 (`PROBATION_REDUCTION_RATE = 0.10`):

1. **1년 이상** 기간을 정한 근로계약일 것 — 1년 미만 계약직·기간 정함 없이 수습만 둔 경우 ○,
   1년 미만 계약이면 감액 불가.
2. 수습 시작일부터 **3개월 이내**일 것 — 4개월째부터는 100%.
3. **단순노무직(한국표준직업분류 대분류 9)이 아닐 것** — 배달원·청소원·경비원 등
   단순노무직은 수습이어도 감액 불가.

셋 중 하나라도 어긋난 감액은 최저임금법 위반 — 미달분은 무효이고 최저임금액 지급 약정으로
간주된다 (제6조③).

## 4. 갱신 절차 (매년 반복 — 운영 체크리스트)

1. **매년 8월 초** 고용노동부 고시 확인 (최저임금법 제10조 — 8월 5일까지 고시).
   확인처: 고용노동부 고시, 최저임금위원회(minimumwage.go.kr), law.go.kr 행정규칙.
2. `labor_constants.MINIMUM_WAGE`에 이듬해 값 추가 — 테이블에 없는 연도를 조회하면
   `minimum_wage()`가 ValueError를 내도록 설계되어 있어(조용한 최신값 대체 금지) 갱신을
   빠뜨리면 이듬해 1월 분석이 즉시 실패한다. 이것이 의도된 안전장치.
3. 이 문서의 1절 표에 같은 값을 추가 (월 환산액 = 시급 × 209, 고시일 병기).
4. `check_minimum_wage`·`analyze_payroll` 골든 테스트를 새 연도 값으로 재실행.

> **한계 고지**: 월 환산액 209시간은 주 40시간 전일제 기준 관행값이다. 단시간·교대제는
> 반드시 사업장별 소정근로시간으로 환산 기준을 재산출할 것 (`monthly_standard_hours()`).
